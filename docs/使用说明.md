# 最强软件使用说明

## 1. 软件简介

“最强软件”是 Windows 桌面 AI 创作助手，支持模型对话、提示词组合、音乐、音效、图像、视频分镜和 3D 世界提示词生成。

## 2. 模型配置

当前默认服务地址为 `https://llm.goaichat.top/v1`，支持 DeepSeek V4 Pro、DeepSeek V4 Pro (0813)、GLM 5.3 和 Kimi K3。

模型设置中可以切换服务商、模型、API Key 和温度。默认聊天请求使用较大的输出预算和高思考强度；如果服务商不支持某参数，会按服务商返回的错误提示处理。

## 3. 提示词组合

在提示词选择器中依次选择“提示词”“思考”“输出”，再发送你的具体需求。

### 提示词类别

| 类别 | 条目 | 用途 |
| --- | --- | --- |
| 音乐生成 | Udio 预告片音乐 | 电影预告片、史诗配乐提示词 |
| 音频特效 | SFX | 带时间顺序的声音事件描述 |
| 图像生成 | Midjourney | 图像生成提示词 |
| 图像生成 | 角色拆解图 | 角色服装、表情、道具和材质拆解 |
| 视频分镜 | 中文视频分镜 | 单场景多镜头分镜 |
| 视频分镜 | 对话分镜 | 正反打、过肩、反应链和轴线管理 |
| 视频分镜 | 场景列表 JSON | 从故事中提取结构化场景 |
| 3D 世界 | 世界构建 | 可探索 3D 环境描述 |

### 思考方式

- **深度思考**：加入内置思考协议，适合复杂创作任务。
- **无思考**：直接生成结果，适合简单、快速的请求。

### 输出格式

- Udio 音乐提示词
- Midjourney 图像提示词
- 中文视频分镜
- 对话分镜
- 场景列表 JSON
- 角色拆解图

## 4. 推荐流程

1. 新建会话并选择模型。
2. 选择提示词类别和条目。
3. 选择深度思考或无思考。
4. 选择输出格式。
5. 输入主题、人物、场景、风格和限制条件。
6. 发送消息并复制生成结果到目标工具。

## 5. 示例

选择“图像生成 → Midjourney”，思考选择“深度思考”，输出选择“Midjourney 图像提示词”，然后输入：

```text
雨夜霓虹街道上的机械猫，电影感，蓝紫色灯光
```

选择“视频分镜 → 中文视频分镜”可生成单场景连续分镜；选择“场景列表 JSON”可把故事文本整理为结构化场景数据。

## 6. 常见问题

- 无法对话：检查网络、API 地址、API Key 和当前模型是否可用。
- 黑屏：确认使用正式安装包，不要使用依赖 `localhost:1420` 的开发版。
- 组合器报错：至少选择一个思考方式或输出格式。
- 更新安装：新版安装包使用同一应用标识，会覆盖旧版本并保留用户数据。
