# 最强软件技术说明

## 技术栈

- 前端：React、Vite、JavaScript bundle
- 桌面容器：Tauri 2
- 原生后端：Rust
- 数据库：SQLite（rusqlite bundled）
- HTTP：reqwest，支持 OpenAI-compatible Chat Completions 流式响应
- 打包：NSIS，Windows x64

## 目录结构

```text
src/                       前端入口
dist/                      已构建前端资源
src-tauri/src/             Rust 命令、数据库和提示词目录
src-tauri/tauri.conf.json  Tauri 产品和打包配置
docs/                      使用说明、技术文档和截图
releases/                  发布安装包
```

## 提示词接口

后端命令位于 `src-tauri/src/commands.rs` 和 `prompts.rs`：

```text
get_prompt_categories_safe()
get_thinking_methods_safe()
get_output_formats_safe()
compose_system_prompt(categoryId, itemId, thinkingId, outputId)
compose_prompt_preview(categoryId, itemId, thinkingId, outputId)
```

组合顺序为：基础提示词、可选思考协议、可选输出约束，各段使用两个换行拼接。

## 聊天请求

`stream_chat_raw` 接收消息、API Key、Base URL、模型、温度、最大输出长度和思考强度，并向：

```text
{base_url}/chat/completions
```

发送 OpenAI-compatible JSON。默认使用流式响应，后端通过 Tauri 事件转发 `chat-raw-chunk`、`chat-raw-end` 和 `chat-raw-error`。

## 数据与安全

- 聊天记录存放在 Tauri 应用数据目录下的 SQLite 数据库。
- `node_modules/`、`src-tauri/target/`、数据库和本地媒体文件不进入 Git。
- 本仓库为 Private。当前构建曾包含内置 API 配置；公开仓库前应改为环境变量或用户设置，并轮换已经暴露过的 Key。

## 构建发布

```powershell
npm install
npx tauri build
```

版本号需要同步更新：`package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 和 `src-tauri/tauri.conf.json`。

NSIS 安装包位于：

```text
src-tauri/target/release/bundle/nsis/
```

应用标识保持 `com.zuiqiangruanjian.desktop`，这样新版本安装时会覆盖旧版本。
